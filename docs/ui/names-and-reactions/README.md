# Names, reaction tooltips and message toolbar evidence

Captures of actual GPUI windows using the offline demo fixtures. All people and conversations are fictional; no Keybase account was used.

Before captures are `main` at 93b88b1; after captures are this branch. Reproduce with `scripts/ui_preview/capture.sh chat members preferences reaction-tooltip`.

Two scenes need a local, uncommitted patch: the demo cannot hold a hover or a reaction tooltip while the pointer is outside the window, and the username capture needs the setting forced on at launch.
