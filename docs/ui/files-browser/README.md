# Files sidebar evidence

These are crops of actual GPUI windows using offline demo fixtures. All people, conversations, filenames, and preview images are fictional. No Keybase account or user files were used.

Before captures use the main branch renderer plus the new fixture scenes. After captures use this branch. Both use the same data and 360px pane width, in light and dark themes.

Reproduce the after scenes with `scripts/ui_preview/capture.sh files-media files-documents files-empty`. The capture script uses a temporary data directory and skips the backend. On this machine the shell screenshot API failed, so the captured windows were exported through computer use and cropped to their sidebars.
