`keybase-shortcodes.json` contains standard Unicode emoji aliases from Keybase's
`go/chat/storage/emoji_codemap.go` at commit
`e6ac912d418ccde5419498d2379665621fa3b467`:
https://github.com/keybase/client/blob/e6ac912d418ccde5419498d2379665621fa3b467/go/chat/storage/emoji_codemap.go

Regenerate with:

    python3 scripts/generate_keybase_emoji_aliases.py /path/to/keybase-client/go/chat/storage/emoji_codemap.go

These are standard aliases, separate from conversation-scoped custom emoji assets.
Keybase's BSD license is retained in `LICENSE.keybase` and copied into macOS bundles.
